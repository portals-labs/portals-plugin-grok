# Portals plugin for Grok Build

Build, manage, and publish [Portals](https://portals.to/) browser games from Grok Build —
the `portals-web-games` MCP server plus skills carrying the platform documentation.

## Install

```sh
grok plugin marketplace add portals-labs/portals-plugin-grok
grok plugin install portals-plugin-grok@portals-plugin-grok --trust
grok plugin enable portals-plugin-grok
```

Press `r` in the Plugins tab or start a new session, then confirm the installed skills and
MCP server with `grok plugin details portals-plugin-grok` and `grok inspect`. The MCP server
is a self-contained bundle that needs Node 18+ and no package-install step.

Disable any Claude-compatible Portals plugin in Grok before enabling this native package; both
expose the same skill and MCP server names.

Refresh a later release with `grok plugin marketplace update`, then
`grok plugin update portals-plugin-grok`.
